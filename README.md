# 🛒 KiranaKart : E-Commerce Platform

A full-stack e-commerce application built with **Java Spring Boot**, **React TypeScript**, **PostgreSQL**, and **Tailwind CSS**.

## 🚀 Features

- 🔐 JWT Authentication & Authorization
- 📦 Product Catalog with Categories
- 🛍️ Shopping Cart Management
- 💳 Stripe Payment Integration
- 📊 Admin Dashboard & Inventory Management
- 📧 Email Notifications (SendGrid)
- ⭐ Product Reviews & Ratings
- 🔍 Advanced Search & Filters
- 📱 Responsive Design

## 🛠️ Tech Stack

### Backend
- Java 17
- Spring Boot 3.x
- Spring Security (JWT)
- Spring Data JPA + Hibernate
- PostgreSQL
- Liquibase
- Lombok & MapStruct
- Stripe API
- SendGrid API

### Frontend
- React 18
- TypeScript
- MobX (State Management)
- React Router v6
- Tailwind CSS
- React Hook Form + Zod
- Axios
- React Hot Toast

## 📋 Prerequisites

- Java 17+
- Node.js 18+
- PostgreSQL 14+
- Maven 3.8+
- pnpm
